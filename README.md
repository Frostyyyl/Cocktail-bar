# Cocktail-Bar
Project made for Mobile Applications laboratories at Poznań University of Technology.

# Description
This Android application is built using Kotlin in Android Studio and provides users with a catalog of cocktail recipes, powered by [TheCocktailDB API](https://www.thecocktaildb.com/). It showcases clean architecture and modern Android development practices with two distinct UI layout versions managed across separate Git branches.

# Branches
**main**: Implements the original layout design. It features a straightforward and functional UI for listing and viewing cocktail recipes.
**new-design**: Contains a redesigned UI with improved visual styling and user experience, including enhanced navigation, updated color scheme, and more engaging presentation of recipe details.
